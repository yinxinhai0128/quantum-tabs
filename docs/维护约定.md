# 维护约定

主理人负责判断专业内容、公开边界与招聘状态；AI协助分类、摘要、排版和提交。
这是一个公开资料夹，不是私有客户系统或候选人数据库。

## 平时怎么用
在维护本仓库的聊天里直接发送相关链接、可以公开的岗位内容或你自己的观察即可。
AI将整理相关内容、保留来源、更新索引，并在实际推送成功后给出提交链接。
如果只是讨论草稿，可以注明“先讨论不公开”；不需要保存的内容注明“不要入库”。
含客户、候选人或其他私人信息的材料不进入公开仓库，是否可公开有疑问时先确认。

## 收录格式
每条资料至少包含标题、方向、来源机构、原始链接、整理说明和收录日期。
收录日期不冒充原文发布日期。动态政策、活动与岗位另行核对截止时间、适用范围和当前状态。
不把无法核实的信息补成事实，不把未经主理人确认的推测写成主理人观点。
同一资料已有记录时更新旧记录，避免反复收录。

## 岗位
使用稳定岗位编号，发布脱敏版。未给出的条件明确待确认。
停止展示时同步修改岗位Markdown、索引和网页数据；需要保留历史的记录明确标识状态。
隐藏公司名不能保证完全不可识别，独特项目与团队线索也需要审查。

## 网站和仓库
GitHub保存公开内容和网页源码。仓库提交不会自动更新其他托管平台上的网页。
网页部署继续按照主理人已经选择和授权的方式执行。
本地私人资料、缓存、截图、部署凭据和托管平台配置均不上传。

## 跨聊天继续
AI不会后台监听全部聊天。新聊天需要提供仓库链接，并让AI先读取AGENTS.md。
